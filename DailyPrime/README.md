# Daily Prime — Android Studio Project

Daily Prime is an Android application built with Kotlin and Jetpack Compose.

## Build an APK with GitHub Actions (recommended)

This repository includes `.github/workflows/android.yml`.

1. Create a new **public or private** GitHub repository.
2. Extract this ZIP file on your computer.
3. Open the extracted `DailyPrime` folder. It must contain `app/`, `build.gradle.kts`, `settings.gradle.kts`, and `.github/`.
4. Upload **the contents of the `DailyPrime` folder** to the root of your GitHub repository (do not upload the ZIP as a single file and do not create an extra nested `DailyPrime/DailyPrime` folder).
5. Commit the files to the `main` branch.
6. Open the repository on GitHub and select **Actions**.
7. Open **Build DailyPrime APK**. The workflow starts automatically after a push. You can also choose **Run workflow**.
8. Wait until the workflow has a green check mark.
9. Open the completed workflow run, scroll to **Artifacts**, and download **DailyPrime-debug-apk**.
10. Extract the downloaded artifact ZIP. It contains `app-debug.apk`.

The APK generated by this workflow is a **debug APK** for testing and direct installation. It is not a Play Store release build.

## Build locally with Android Studio

1. Install Android Studio and JDK 17.
2. Open this `DailyPrime` folder (the folder containing `settings.gradle.kts`).
3. Install Android SDK Platform 34 and Build-Tools 34.0.0 from SDK Manager.
4. Let Gradle sync finish. The project uses Android Gradle Plugin 8.5.2, Kotlin 2.0.20, and Gradle 8.7.
5. Select **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. Find the APK at `app/build/outputs/apk/debug/app-debug.apk`.

## Project configuration

- Application ID: `com.dailyprime.app`
- Minimum Android version: Android 8.0 (API 26)
- Compile / Target SDK: 34
- Java target: 17
- Version: 1.0.0 (versionCode 1)

## Notes

- Do not commit signing keys, passwords, API secrets, or `local.properties`.
- GitHub Actions must finish successfully before an APK can be downloaded.
- This repository currently builds a debug APK. A separately configured release signing key is required for a signed release APK suitable for distribution.
